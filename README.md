# 행정지침 검토 도우미 (AI 기반 대학 행정지침 검토 및 집행사례 관리)

대학 교직원이 **자기 PC에서 혼자 쓰는** 웹 프로그램입니다.
기안문·지출결의서·결과보고서 등을 올리면 AI가 등록된 교육부·지자체·교내 지침과 과거 집행사례를 참고해
예산 집행 적정성을 검토합니다. 지침이 불명확한 항목은 AI가 추가 질문을 하고, 담당자의 답변과 관련 문서를
이 PC에 저장해 다음 검토 때 다시 참고합니다.

> ⚠️ **완전한 오프라인 프로그램이 아닙니다.** AI 검토를 실행하면 업로드한 문서, 등록된 지침, 관련 과거 사례의
> 내용이 **외부 OpenAI API로 전송**됩니다. 지침·사례 DB·첨부파일은 이 PC의 `data/` 폴더에만 저장됩니다.

> ※ AI의 "적합" 판정은 검토 의견일 뿐 법적 적정성을 보증하지 않습니다.

## 1. Python 설치 확인

명령 프롬프트(cmd)를 열고 입력합니다.

```
py --version
```

`Python 3.11` 이상이 나오면 됩니다. 없거나 낮으면 <https://www.python.org/downloads/> 에서 설치하세요.
설치 첫 화면에서 **"Add python.exe to PATH"** 를 반드시 체크합니다.

## 2~5. 가장 쉬운 실행 방법: `start.bat` 더블클릭

프로젝트 폴더의 **`start.bat`** 을 더블클릭하면 아래 과정을 자동으로 합니다.

1. 가상환경(`.venv`) 생성 (처음 한 번)
2. 필요한 패키지 설치 (처음 한 번, 몇 분 소요)
3. `.env` 파일이 없으면 만들고 메모장으로 열어 줌 → `OPENAI_API_KEY` 입력 후 저장, 메모장 닫기
4. 프로그램 실행 → 브라우저에서 `http://127.0.0.1:8501` 이 열림

종료할 때는 검은 창에서 `Ctrl+C` 를 누르거나 창을 닫습니다.

> 명령 프롬프트에서 실행할 때는 `start.bat` 이 아니라 **`.\start.bat`** 으로 입력하세요.
> (`start` 는 cmd의 내장 명령어라서 그냥 `start.bat` 이라고 치면 인식되지 않습니다. 더블클릭은 문제없습니다.)

### 직접 실행하려면 (수동 설치)

```
cd 프로젝트폴더
py -3 -m venv .venv                       :: 2. 가상환경 생성
.venv\Scripts\activate                    ::    가상환경 켜기
pip install -r requirements.txt           :: 3. 패키지 설치
copy .env.example .env                    :: 4. 설정 파일 만들기 → 메모장으로 열어 API 키 입력
streamlit run app.py                      :: 5. 실행 (127.0.0.1:8501)
```

### 4. OpenAI API 키 설정

1. <https://platform.openai.com/api-keys> 에서 API 키를 발급합니다(유료 결제 설정 필요).
2. `.env` 파일을 메모장으로 열어 `OPENAI_API_KEY=` 뒤에 키를 붙여 넣고 저장합니다.
3. 모델을 바꾸려면 `OPENAI_MODEL` 을 수정합니다(기본값 `gpt-4.1-mini`, 본인 계정에서 쓸 수 있는 모델이어야 함).
4. `.env` 를 수정한 뒤에는 프로그램을 껐다 켜야 반영됩니다.

| 설정 | 설명 | 기본값 |
|---|---|---|
| `OPENAI_API_KEY` | OpenAI API 키 (소스코드에 넣지 마세요) | (필수) |
| `OPENAI_MODEL` | 사용할 모델 이름 | `gpt-4.1-mini` |
| `OPENAI_TIMEOUT` | AI 응답 대기 시간(초) | 180 |
| `MAX_INPUT_CHARS` | AI 1회 입력 최대 글자 수. 모델 입력 한도에 맞춰 조정(128k 토큰 모델이면 100000 권장) | 300000 |
| `PAST_DOC_MAX_CHARS` | 과거 사례 원본 문서 1개당 AI에 넣는 최대 글자 수 | 20000 |
| `MAX_SELECTED_CASES` | AI가 고를 수 있는 과거 사례 최대 개수 | 5 |
| `MAX_FILE_MB` | 업로드 파일 1개당 최대 크기(MB, 50 이하) | 20 |

## 6. 지침 파일 등록 방법

1. 왼쪽 메뉴에서 **지침 관리** 선택
2. PDF·DOCX·TXT 지침 파일을 끌어다 놓고 **지침 등록** 클릭
3. 목록에서 "텍스트 추출 정상 (n자)" 표시를 확인합니다.
   - 스캔(이미지)형 PDF는 텍스트를 뽑을 수 없어 등록되지 않습니다(OCR 미지원). 텍스트 PDF·DOCX·TXT로 변환해 주세요.
   - HWP/HWPX는 지원하지 않습니다. 한글에서 PDF 또는 DOCX로 저장해 올리세요.
4. 필요 없는 지침은 **삭제** 버튼으로 지웁니다.

지침 전체 분량이 `MAX_INPUT_CHARS` 를 넘으면 경고가 나오며, **내용을 몰래 잘라서 검토하지 않습니다.**
이때는 검토 화면의 "검토에 사용할 지침"에서 관련 지침만 골라 주세요.

## 7. 행정문서 검토 및 사례 저장 방법

**신규 문서 검토** 화면(메인 화면)에서:

1. **검토할 행정문서**(대표 문서 1개)와 **추가 증빙자료**(여러 개 가능)를 올립니다.
2. **AI 검토 실행** 을 누르면 다음 단계가 자동으로 진행됩니다.
   1. 공식 지침 분석 – 집행항목별로 `적합` / `위반 가능성` / `판단 불가` 분류, 관련 지침 인용
      (AI가 인용한 문장이 실제 지침 원문에 없으면 ⚠️ 표시)
   2. 과거 사례 분석 – 저장된 사례 **전체**를 AI에 보여 주고 관련 사례 번호를 고르게 함
   3. 원본 문서 확인 – AI가 고른 사례의 **저장된 첨부파일을 실제로 열어** 내용을 읽음(고르지 않은 사례의 파일은 열지 않음)
   4. 추가 질문 생성 – `위반 가능성`·`판단 불가` 항목마다 질문 1개 (`적합` 항목은 질문하지 않음)
3. 각 질문 아래 **담당자 답변**을 입력하고 **답변 반영 및 최종 의견 생성** 을 누릅니다.
4. 최종 의견(지침 검토 결과, 담당자 설명, 과거 사례, 남은 불확실성, 추가 증빙, 종합 의견)을 확인합니다.
   답변이 있어도 지침이 허용하지 않는 지출은 적합으로 보지 않으며, 공식 지침과 과거 관행을 구분해 보여 줍니다.
5. **사례 DB 저장** 을 누르면
   - 답변한 `위반 가능성`·`판단 불가` 항목만 `data/cases.db` 에 저장되고 (`적합`·미답변 항목은 저장 안 함)
   - 업로드한 문서가 `data/documents/case_XXX/` 에 복사됩니다(한 문서의 여러 항목은 같은 폴더를 함께 참조).
   - 같은 내용은 두 번 눌러도 중복 저장되지 않습니다. 저장 중 오류가 나면 저장한 파일과 DB 기록을 되돌립니다.

AI 호출이 실패하거나 응답 형식이 잘못되면 오류 안내와 함께 **다시 시도** 버튼이 나오며, 이미 끝난 단계는 다시 실행하지 않습니다.

**저장된 사례** 화면에서 사례 목록, AI 질문·답변, 검토 결과를 보고 첨부파일을 열거나 내려받을 수 있습니다(사례 삭제도 가능).

> ⚠️ 저장된 문서의 파일명이나 폴더 위치를 임의로 변경하거나 파일을 삭제하면 이후 AI가 과거 사례의 원본 문서를 확인할 수 없습니다. 해당 폴더의 파일은 프로그램을 통해 관리해 주세요.
>
> 첨부파일이 없어진 경우에도 프로그램은 멈추지 않고 "과거 사례의 첨부파일을 찾을 수 없습니다" 경고 후 DB의 질문·답변만으로 검토합니다.

## 8. 로컬 데이터 백업 방법

모든 데이터는 `data/` 폴더 하나에 있습니다.

```
data/
├─ guidelines/     등록한 지침 파일
├─ documents/      사례별 원본 문서 (case_001/, case_002/ ...)
└─ cases.db        사례 DB (SQLite)
```

- **백업:** 프로그램을 끈 뒤 `data` 폴더 전체를 USB·외장 디스크 등에 복사합니다.
- **복원:** 프로그램을 끈 뒤 백업한 `data` 폴더로 통째로 바꿔 넣습니다.
- `cases.db` 만 따로 옮기거나 `documents` 안의 파일 이름을 바꾸면 사례와 파일 연결이 끊어집니다. 항상 폴더째 다루세요.
- 프로그램을 다시 시작해도 저장된 사례와 파일은 그대로 유지됩니다. 폴더나 DB가 없으면 실행 시 자동으로 만듭니다.

## 9. 외부 API 사용 및 보안 유의사항

- AI 검토 시 문서·지침·관련 과거 사례(첨부 문서 내용 포함)가 **OpenAI 서버로 전송**됩니다.
  개인정보(주민등록번호, 계좌번호 등)나 대외비 문서는 전송 전에 가리거나 제외하세요.
- API 키는 `.env` 파일에만 넣고, 소스코드나 메신저·이메일에 붙여 넣지 마세요. `.env` 와 `data/` 는 `.gitignore` 에 등록되어 git에 올라가지 않습니다.
- `start.bat`은 `127.0.0.1`(이 PC)에서만 접속됩니다. 다른 PC에서 접속하게 하려면 아래 **10. 웹 모드**를 쓰세요. 인터넷에 직접 공개(공유기 포트포워딩 등)하지 마세요.
- 업로드 파일은 PDF·DOCX·TXT, 1개당 `MAX_FILE_MB` 이하만 받습니다.
- DB에 저장된 파일 경로가 `data/documents/` 밖을 가리키면 열지 않습니다.
- 문서 안의 "이전 지시를 무시하라" 같은 문장은 AI에게 검토 대상 데이터로만 전달되며 명령으로 취급하지 않도록 프롬프트를 구성했습니다(완벽한 차단을 보장하지는 않음).
- `start.bat`(혼자 쓰기)은 로그인 기능이 없으므로 이 PC를 다른 사람과 함께 쓰는 경우 `data` 폴더 접근에 유의하세요.

## 10. 웹 모드: 같은 네트워크의 다른 PC에서 브라우저로 접속 (`start_web.bat`)

이 PC를 서버로 켜 두면, 같은 와이파이·사내망에 있는 사람이 설치 없이 브라우저로 접속해 쓸 수 있습니다.

| | 혼자 쓰기 (`start.bat`) | 웹 모드 (`start_web.bat`) |
|---|---|---|
| 접속 | 이 PC만 | 같은 네트워크의 모든 PC |
| 로그인 | 없음 | 없음 (주소만 알면 바로 사용) |
| 데이터 | `data/` | `data/` — 접속한 모든 사람이 같은 지침·사례를 함께 봄 |
| OpenAI API 키 | **환경 설정** 화면 (비워 두면 `.env`) | 각자 **환경 설정** 화면에서 입력 (서버 `.env` 키는 쓰지 않음, 요금은 각자 부담) |

**서버 PC 준비**
1. `start_web.bat`을 더블클릭합니다. 창에 접속 주소(예: `http://10.10.70.77:8501`)가 표시됩니다.
2. 처음 실행할 때 **Windows 방화벽 창이 뜨면 "개인 네트워크" 허용**을 누릅니다. 이걸 안 하면 다른 PC에서 접속되지 않습니다.
   (이미 거부했다면: Windows 보안 → 방화벽 → "방화벽에서 앱 허용"에서 Python을 개인 네트워크로 허용)
3. 사용하는 동안 이 PC와 창을 켜 두어야 합니다(절전 모드 해제 권장).

**사용자**
1. 브라우저에서 알려 받은 주소로 접속하면 바로 화면이 열립니다.
2. 왼쪽 메뉴 **환경 설정**에서 OpenAI API 키·AI 모델·화면 테마(라이트/다크)를 정하고 **설정 저장**을 누릅니다.
   설정은 그 브라우저의 쿠키에만 저장되어 다음 접속 때도 유지되며, 다른 사람에게는 공유되지 않습니다.

**유의사항**
- 로그인이 없으므로 **같은 네트워크에서 주소를 아는 사람은 누구나** 등록된 지침·저장된 사례·첨부파일을 보고 삭제할 수 있습니다. 민감한 문서는 올리지 마세요.
- 접속은 암호화되지 않은 `http`입니다. API 키가 네트워크 안에서 평문으로 전달되므로 **신뢰할 수 있는 사내망에서만** 쓰고, 공용 와이파이에서는 쓰지 마세요.
- 데이터는 혼자 쓰기 모드와 같은 `data/` 폴더를 씁니다. 백업은 `data` 폴더째 복사합니다.

## 실제 API 자동 점검 (`live_check.bat`)

위 표의 테스트 1·2·3·6을 실제 OpenAI API로 한 번에 실행하고, 판정 결과와 함께 소요 시간·토큰 수·예상 비용을 보여 줍니다.
`.env`에 API 키를 넣은 뒤 `live_check.bat`을 더블클릭하면 됩니다.

- 실제 데이터(`data/cases.db`)는 건드리지 않고 `data/live_check/<시각>/`에 별도 DB·파일과 `report.json`(AI 응답 전체)을 만듭니다.
- 비용은 `gpt-4.1-mini`일 때만 자동 계산합니다(입력 $0.40, 출력 $1.60 / 100만 토큰). 다른 모델은 토큰 수만 표시하며, 비용을 보려면
  `.venv\Scripts\python.exe scripts\live_check.py --price-in 입력단가 --price-out 출력단가` 로 실행하세요.
- `확인 필요`는 키워드로 자동 판정한 것이므로, 화면에 출력된 질문 문장을 직접 읽고 최종 판단하세요.
- 테스트 4·5(재실행·파일 누락)는 AI 판정과 무관한 프로그램 동작이라 아래 자동 테스트로 검증됩니다.

## 자동 테스트 (API 키 없이 모의 AI로 실행)

```
.venv\Scripts\activate
pip install -r requirements-dev.txt
pytest
```

모의 AI 응답으로 위 시나리오 1~6의 **프로그램 동작**(저장 조건, 파일 복사·경로, 과거 원본 파일 읽기,
파일 누락 처리, 중복 저장 방지, 오류 후 재시도, 입력 한도 경고, 경로 차단, 화면 동작)을 검증합니다.
AI가 실제로 올바른 판정을 내리는지(예: 테스트 6에서 적합으로 바꾸지 않는지)는 실제 API로 확인해야 합니다.
